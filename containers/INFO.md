
# containers

This directory is a central location for all built containers, both images (.sif) and sandboxes (.sb). Images are to be used primarily, but sandboxes can be opened in writable mode to facilitate exploration, development, debugging, and troubleshooting.

Containers are NOT tracked by git due to their large size. Be sure to copy containers to a more permanent location if it is important to keep them. Otherwise, the repeatable nature of the container-building workflow makes it efficient to recreate containers from a new repo instance.
